# 💰 MoneyTrack

Sistema fullstack para controle financeiro pessoal.

## 🚀 Tecnologias

### Backend
- Node.js
- Express
- PostgreSQL
- Prisma
- JWT (autenticação)
- Bcrypt (criptografia de senha)

## 🔐 Funcionalidades

- Cadastro de usuário
- Login com JWT
- Criptografia de senha
- CRUD de transações (income / expense)
- Proteção de rotas com autenticação

## 📦 Estrutura

backend/
 ├── controllers
 ├── services
 ├── routes
 ├── middlewares
 └── config

## ⚙️ Como rodar o projeto

```bash
cd backend
npm install
npm run dev
